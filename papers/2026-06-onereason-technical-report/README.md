## 初步定位

这是一篇来自快手 OneRec Team 的生成式推荐技术报告，核心目标是解释并解决推荐场景中 `thinking mode` 过去不稳定优于 `non-thinking mode` 的问题。论文将有效推荐推理拆成 itemic-token 语义感知和推荐专用认知推理两部分，并通过预训练、SFT、RL 以及线上 Fast-Slow Thinking 部署来验证。
